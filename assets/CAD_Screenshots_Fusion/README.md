# CAD Screenshots — Autodesk Fusion (Design Model)

## Overview

This folder contains raw, in-application screenshots captured directly from
Autodesk Fusion 360 during the modeling phase of the AeroAcoustix VIP cabin
compartment project. These images document the CAD tree structure, component
hierarchy, material assignments, and iterative visual checks performed while
building the model — including views from Fusion's native Render workspace.
