# Engineering Drawings — AeroAcoustix

## Overview

This folder contains the formal engineering drawing set for the AeroAcoustix VIP
cabin compartment, exported from CAD as a 23-sheet technical drawing package.
Sheets include title blocks, bills of materials (parts lists), dimensioned
orthographic/isometric views, and structural detail callouts.

## Materials Used

- **Titanium — High-Strength Alloy** (primary structure)
- **CFRP** (Carbon Fiber Reinforced Polymer) — outer skin, partitions, fire isolation
- **GFRP** (Glass Fiber Reinforced Polymer) — intermediate structural layers
- **Polyurethane Foam** — acoustic/damping fill
- **Aluminum 6061** — door hardware/fittings
- **PC/ABS Plastic** — door trim components
